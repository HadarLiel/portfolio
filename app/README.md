# Hadar Harush | Personal Portfolio

A modern, responsive personal portfolio website designed to showcase my recent projects, technical skills, and experience as a Lead Full-Stack Developer. Built with a focus on smooth animations, clean UI/UX, and high performance.

## 💻 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Library:** [React](https://reactjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Language:** TypeScript / JavaScript
- **Deployment:** Vercel / Cloudflare Pages

## ✨ Features

- **Modern UI/UX:** Midnight dark theme with glassmorphism elements, soft glow effects, and gradient typography.
- **Smooth Animations:** Integrated Framer Motion for scroll-triggered reveal animations, staggered list rendering, and interactive hover states.
- **Fully Responsive:** Mobile-first approach ensuring a seamless experience across all devices (Desktop, Tablet, Mobile).
- **Dynamic Project Showcase:** Optimized image rendering using Next.js `<Image />` component with error handling fallbacks.
- **Fast Performance:** Server-Side Rendering (SSR) and optimized asset delivery via Next.js.

## 🛠️ Getting Started

To run this project locally, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone [https://github.com/HadarLiel/portfolio.git](https://github.com/HadarLiel/portfolio.git)

2. Navigate to the project directory:
    ```Bash
    cd portfolio

3. Install the dependencies:
    ```Bash
    npm install

4. Start the development server:
    ```Bash
    npm run dev
    Open http://localhost:3000 in your browser to see the result.
